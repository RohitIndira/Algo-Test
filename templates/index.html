Strategy Description
How this strategy works:
  1. Fetches data for stocks in the 20% price band from NSE
  2. Monitors the current market price (CMP) of these stocks
  3. Places a buy order when CMP crosses the 5-day high price
  4. Sets a stop loss at 98% of the day's high price
  5. Automatically squares off all positions at 3:25 PM
Requirements:
  • B2C API credentials
  • User ID and Password
  • TOTP Secret for authentication
  • Internet connection for market data
